# 🎵 PyTune

**PyTune** — лёгкий десктопный аудиоплеер на Python + PyQt6 с поддержкой множества форматов, редактором тегов и удобным управлением с клавиатуры.

---

## ✨ Возможности

### 🎧 Поддерживаемые форматы
| Формат | Расширение |
|--------|-----------|
| MP3 | `.mp3` |
| WAV | `.wav` |
| FLAC | `.flac` |
| Ogg Vorbis | `.ogg` |
| Opus | `.opus` |
| AAC / M4A | `.aac`, `.m4a` |
| WMA / ASF | `.wma`, `.asf` |

### 🏷️ Редактирование тегов
Встроенный редактор метаданных позволяет изменять информацию прямо в плеере:
- **Название** и **исполнитель** трека
- **Обложка альбома** — загрузка из файла (JPG, PNG, BMP, WebP) или удаление
- **Текст песни** — просмотр и правка в отдельной вкладке
- Изменения сохраняются непосредственно в аудиофайл через `mutagen`

### ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|---------|
| `Space` | Воспроизведение / Пауза |
| `Ctrl + O` | Открыть файлы |
| `Ctrl + E` | Редактировать теги выбранного трека |
| `Delete` | Удалить трек из плейлиста |
| `→` / `←` | Перемотка ±5 секунд |
| `Shift + →` / `Shift + ←` | Перемотка ±30 секунд |
| `↑` / `↓` | Громкость +5 / −5 |
| `Ctrl + →` / `Ctrl + ←` | Следующий / предыдущий трек |
| `Ctrl + S` | Включить / выключить случайный порядок |
| `Ctrl + R` | Переключить режим повтора |
| Медиаклавиши | Воспроизведение, стоп, следующий, предыдущий |

### 📂 Перетаскивание (Drag & Drop)
- Перетащите один или несколько аудиофайлов **из проводника** прямо в окно плеера — они мгновенно добавятся в плейлист
- Перетащите **папку** — PyTune рекурсивно добавит все поддерживаемые файлы внутри
- Треки в списке можно **менять местами** перетаскиванием мышью

### 🔀 Дополнительно
- Режимы повтора: без повтора → повтор одного трека → повтор всего плейлиста
- Случайный порядок воспроизведения
- Поиск по названию и исполнителю в режиме реального времени
- Отображение обложки и текста песни для текущего трека
- Автосохранение плейлиста между сессиями

## 🚀 Установка

### Вариант 1 — Готовый `.exe` (Windows)

1. Перейдите на страницу [Releases](../../releases)
2. Скачайте `PyTune.exe` из последнего релиза
3. Запустите файл — установка не требуется

> **Примечание:** при первом запуске Windows Defender может показать предупреждение — нажмите «Подробнее» → «Всё равно запустить».

---

### Вариант 2 — Запуск из исходников

**Требования:** Python 3.10+

**1. Клонируйте репозиторий**
```bash
git clone https://github.com/your-username/pytune.git
cd pytune
```

**2. Установите зависимости**
```bash
pip install PyQt6 mutagen
```

**3. Запустите плеер**
```bash
python PyTune.py
```

#### Сборка `.exe` самостоятельно (опционально)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name PyTune PyTune.py
```
Готовый файл появится в папке `dist/`.
